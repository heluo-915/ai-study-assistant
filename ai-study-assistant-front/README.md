# 知页 · AI 学习助手前端

使用 Vue 3 + Vite。启动前请先在 IDEA 运行 `ai-study-assistant` 后端（默认 `localhost:8080`）。

```sh
npm install
npm run dev
```

打开终端提示的地址。Vite 开发服务器会将 `/api` 请求代理到后端，具体配置见 `vite.config.js`。如需调整后端端口，修改 `target`。

登录凭证保存在当前浏览器标签页的 sessionStorage，关闭标签页或点击退出会清除。支持登录注册、流式会话、笔记创建编辑删除、TXT/PDF 资料导入、关键词与片段语义问答、练习题与错题、学习任务、学习助手，以及向量维度与文本相似度实验。API 凭证仅由后端持有。对话和笔记问答会调用 DeepSeek，可能产生费用。

关键词模式使用字面匹配；语义模式通过后端片段检索与问答接口获取参考片段。相似度和向量维度实验需要后端及本地 Ollama/Embedding 模型处于可用状态。问答结果中所列的参考笔记是传给模型的上下文，不代表逐句引用。

此配置用于本地开发；部署静态文件时需要由服务端代理 `/api` 到后端，并配置适合部署环境的认证、HTTPS 与访问限制。

项目整体介绍见[仓库首页](../README.md)，后端环境配置与数据库初始化见[后端说明](../ai-study-assistant/README.md)。
