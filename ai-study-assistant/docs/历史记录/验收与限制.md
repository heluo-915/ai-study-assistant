## 已知限制

- 检索在 Java 内逐条比较向量，当前取相似度不低于 0.5 的最多 5 个片段。此前合成资料测试发现，相似片段可能挤掉真正有用的证据；扩大候选也可能引入干扰。当前没有改动检索策略。
- 回答中的来源是提供给模型的参考片段，不保证回答的每一句都来自相应片段；生成的答案、题目和解析需要自行核对。小样本测试也不能保证防御所有提示注入。
- PDF 主要支持可提取文字的文档；扫描件 OCR、复杂排版和图片理解不在本版范围内。
- SSE 流在模型正常完成且保存成功后发送 `done`，异常时发送 `error`；同一会话并发、客户端断连及所有代理环境尚未完整验证。检查了模型返回的完成原因，但不保证检测所有缺失流终止标记的情况。
- 错题列表当前最多返回 50 项；作答历史和笔记题目列表支持游标分页。高并发提交的先后顺序尚未全面验证。
- 项目保留学习用的 `/hello`、`/database-check`、`/users/count` 接口；本版没有完成面向公网生产环境的安全加固、运维和压力测试。
- 更换向量模型后，已有向量需要按新模型重新生成；本版没有专用向量数据库，数据量增长后检索性能有待优化。

启动、配置和接口示例见项目根目录的 `README.md`。后续扩展可根据实际需求选择，当前不要求实现 Tool Calling、Redis、消息队列、OCR 或前端。
