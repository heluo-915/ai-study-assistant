# Qdrant 同步任务消费者（手动验证阶段）

`NoteVectorSyncWorker.processPending(userId, noteId)` 仅处理指定的 PENDING 任务：通过数据库原子领取和随机令牌确认身份；UPSERT 先检查笔记归属、获取片段，再按用户和笔记删除旧向量、重新写入；DELETE 删除指定用户与笔记的向量。执行成功后更新任务状态；执行失败时记录 FAILED（如果期间有新版本则回到 PENDING）并抛出异常。

目前不提供 HTTP 接口、不自动扫描和领取任务，也不与笔记业务自动联动。调用方必须传入服务端可信的 userId，不能直接信任客户端输入。测试使用隔离数据库和隔离集合。

重要边界：替换操作是“删除旧向量、逐条写入新向量”，不是跨数据库原子操作。运行中和失败后会暂时没有完整向量，发生异常时必须重试。向量化期间笔记可能继续变化；目前任务登记尚未接入笔记写事务，无法保证自动发现这种变化。进程退出或数据库故障可能让任务停在 RUNNING；目前没有租约、心跳或自动恢复，不能在不能确认旧执行者停止时强制重置，否则可能出现旧任务覆盖新数据。当前实现仅作受控验证，不能视为生产级同步。
