# 高优先级修复记录

## 笔记更新与片段一致性

更新前先验证归属，并在数据库事务外准备整篇向量和所有新片段。模型调用失败时不改变原有笔记、向量和片段；接口通过已有模型异常处理返回 HTTP 502。

准备完成后，在一个 MySQL 事务中锁定笔记并核对标题和正文快照，再保存新正文、向量、片段和 Qdrant 同步任务；任一步失败都回滚。若准备期间笔记发生修改，返回 HTTP 409，客户端应刷新后重试。成功后沿用 `UpdateNoteResponse` 返回成功状态。

Qdrant 仍通过异步任务同步，跨库不具备强一致性；同步失败、运行中任务中断和 MySQL 回退等原有限制仍存在。

## 默认鉴权

MVC 拦截器默认保护全部路径，仅排除登录、注册、问候、数据库检查、用户数量和错误路径；CORS 预检不要求 JWT，但是否允许跨域仍由 CORS 配置决定。新增业务接口无需逐项加入保护列表；新增公开接口需要显式审查。

## 验证

使用独立 MySQL 数据库和 Qdrant 集合运行完整回归及专项测试，涵盖模型失败保留旧数据、成功替换、任务登记失败回滚、并发修改冲突、默认鉴权、公开路径、Qdrant 回填与检索。测试数据为合成内容，临时数据库和集合已清理。
