# AI 学习助手：当前项目说明

核对日期：2026-11-16。本说明基于源码和配置静态整理；接口具体参数、响应和运行结果以 Controller、DTO 和实测为准。

## 项目是什么

这是 Java 单体后端，围绕用户的学习笔记提供资料导入、语义检索、问答、练习和复习。DeepSeek 负责生成回答与题目；Ollama 使用 `qwen3-embedding:0.6b` 生成向量。MySQL 保存业务数据和片段向量，Qdrant 保存用于相似检索的索引。

```text
请求 → Controller 校验和获取用户身份 → Service 编排
     → Mapper/Repository 读写 MySQL
     → Ollama 生成向量；后台任务同步 Qdrant
提问 → 检索本人片段 → 校验来源 / 回退 MySQL → DeepSeek → 回答与来源
```

项目存在按整篇笔记、关键词和片段等多种检索路径，上图描述片段问答的主要路径，并非每个接口都会经过 Qdrant。

## 目录与职责

| 位置 | 职责 |
| --- | --- |
| `controller` | HTTP 参数和响应，获取拦截器写入的用户 ID |
| `service` | 业务、外部模型调用、同步与任务编排 |
| `mapper`、`repository` | MyBatis SQL 和用户数据访问 |
| `dto`、`entity` | 接口数据、持久化与业务对象 |
| `security`、`config` | JWT 拦截、密码和任务调度配置 |
| `database/schema.sql`、`database/migrations` | 基础表和按编号执行的升级脚本 |
| `http` | IDEA HTTP 客户端示例 |

## 主要业务链路

- **身份**：注册、登录取得 JWT；`JwtInterceptor` 校验身份。当前默认保护全部路径，注册、登录、`/hello`、`/database-check`、`/users/count`、`/error` 例外。归属由服务端用户 ID 校验。
- **资料**：创建、更新、删除笔记；支持 TXT、可提取文字的 PDF 和异步导入。正文可分片并生成向量。更新流程会先准备向量，再在 MySQL 事务内核对旧内容并保存新数据、登记同步。
- **问答**：支持单篇、关键词、语义与片段问答；来源表示送给模型的参考材料，不保证每句话都有可靠引用。
- **会话**：会话和消息持久化，支持普通问答及 SSE 流式回答。
- **练习**：根据笔记生成选择题，保存作答、统计、错题与学习任务。
- **学习助手**：`StudyAssistantService` 配合只读 `StudyAssistantTools`，模型可按需调用工具查询当前用户的学习数据；是否调用由模型决定。

## Qdrant 同步与检索的实际保证

笔记变更在 MySQL 事务中登记任务；调度器领取并写入 Qdrant。任务有 PENDING、RUNNING、SUCCEEDED、FAILED，普通失败有限次数重试。变更期间有新版本时重新排队。

目前进程中断可能使任务停留 RUNNING；不能安全地仅按超时重置，因为旧执行者可能继续写 Qdrant。手动恢复前必须确认旧执行者已停止。MySQL 与 Qdrant 没有共同提交的事务；搜索会检查状态、数量及返回片段并在异常时回退，但无法发现所有等数量缺失或向量损坏情况，也不提供跨库强一致保证。具体操作见 [Qdrant 接入与验证](Qdrant接入与验证.md)。

## 测试与限制

使用独立测试数据库运行 `mvn test`，部分真实依赖集成测试需要显式启用并准备 MySQL、Qdrant 或 Ollama；具体条件以测试注解和配置为准。单元测试通过不等于外部服务及全部并发场景已验证。PDF OCR、复杂排版、生产安全加固、大规模检索和压力测试仍有边界。项目中的问候及数据库检查接口属于开发演示，不应未经审查暴露公网。
